PolicyGuard

Tiny Aya Global (3.35B) fine-tuned with LoRA to act as a search agent for Indian health-insurance rules. It searches two IRDAI circulars (May 2024 current, July 2020 replaced), cites the passages it used as [chunk N], and says it could not find an answer instead of guessing. Code · Model and dataset

74 answerable held-out test questions, graded by an LLM judge (qwen3.8-27b) against reference answers. Fine-tuning turns the untrained model, which rarely searches and invents citations, into a working search agent. It does not beat a simple always-search pipeline on accuracy (95% CIs 16–35% vs 23–43% overlap); it cites better and rarely refuses answerable questions. Not legal or financial advice.

Run it yourself

Live inference needs the gated base model (accept the license on CohereLabs/tiny-aya-global). On an Apple Silicon Mac: clone the repo and run python src/ask.py "your question", which prints every search step. Elsewhere, load the PEFT adapter with transformers; the model card has the snippet.
